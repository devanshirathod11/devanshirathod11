# Hi, I'm Devanshi Rathod

### AI & Data Systems Engineer | LLM Applications · Data Engineering · AI Evaluation

I build and evaluate AI-driven data systems—from natural-language interfaces to relational databases to reliable AI-powered product workflows.

My experience spans open-source LLMs, Text-to-SQL, retrieval-augmented generation (RAG), vector search, database pipelines, and AI quality engineering. I focus on making AI systems useful, measurable, and reliable.

## About Me

- Building with **LLMs, RAG, and conversational Text-to-SQL**
- Working across **Python, SQL, PostgreSQL, vector databases, and data workflows**
- Evaluating AI systems through **benchmarking, automated output validation, adversarial testing, and prompt-injection testing**
